## 写在前面

今年十一回老家，一件重要的事是把留在家里8年的古筝寄到北京来。多年未弹，甚是想念。

回来之后半个多月一直在做的事就是换弦。因为古筝不弹的情况下，弦仍然有很强的张力，且更容易老化。所以这次需要全部换弦。我陆陆续续用以前的高音备用弦换了几根，结果3弦崩了5次。实在受不了了，就直接买了一整套新弦，再找 AI 好好探讨断弦的原因和换弦的注意事项。最后总结出来下面的操作指南，以供未来参考。

另外，其中总结出来一个很重要的换弦失败的原因：弦的张力问题。当新弦刚刚拧紧，又有码字增加的张力，所以式很容易在迅速增加的张力下断裂。而如果换上新弦，让弦适应一下岳山、弦槽等各个部位的张力，等几个小时或者一天，再来拧紧或者加上码子，那么就不容易应激断裂。

对，弦居然也会应激。这个情况太容易联想到人了。在任何情况下，人也需要给自己一点点时间来适应新的张力和变化。如果短时间内，不断上强度，那么是很容易受伤的。反之，只要一些时间来适应，新的挑战、新的音高就可以到达。

以下是详细的换弦指南：

## 0. 换弦前先判断问题

| 现象 | 最可能原因 | 处理方向 |
|---|---|---|
| 高音弦特别紧、易崩 | 码子太靠左，有效弦长过短；或弦轴缠绕过多、交叉 | 先检查码位，再拆开重绕；不要硬拧 |
| 低音弦不够紧、会回弹 | 弦头未被锁住、缠绕方向不对、弦轴打滑或调音盒异常 | 重穿、重绕，确认弦头被压住；必要时检查弦轴 |
| 拧弦轴没有反应 | 弦在弦轴上交叉、叠绕，或弦头未被压紧 | 全部松开重绕，保持单层平行排列 |
| 弦尾有杂音 | 弦尾没有贴紧弦轴、翘起 | 将弦尾折回并压在后续缠绕圈下 |
| 换弦后很快走音 | 新弦张力未稳定、码子未压实、缠绕点滑动 | 反复按压码子两侧并复调 |

## 1. 通用安全原则

- **先松后拆**：换弦前先将旧弦完全放松，再取下码子附近压力，避免突然崩弦。
- **使用同型号、同弦号琴弦**：不同弦号的粗细、张力和音色设计不同，不可混用。
- **弦轴孔方向要便于穿弦**：穿弦前把弦轴小孔转到便于穿弦、且后续缠绕不会压到相邻弦的位置。
- **缠绕必须单层、平行、方向一致**：不要交叉、不要叠成小团；交叉会增大局部张力，也可能导致调音不顺或断弦。
- **弦头必须被压住**：穿出弦轴孔后，将短端折回、紧贴弦轴，让后续第一圈压住弦头，否则弦会滑动回松。
- **不要一次调到位**：先建立基础张力，再放码子、逐步调到接近标准音；新弦需要反复按压和复调。
- **高音区宁少勿多**：缠绕圈数宜少而整齐；低音区可稍多，但仍以不交叉、不叠压为前提。

## 2. 通用换弦流程

### 2.1 准备工具

- 同型号、同弦号新琴弦
- 调音扳手
- 调音器
- 可选：小钳子、软布、筝码位置标记贴

### 2.2 操作步骤

| 步骤 | 操作 | 关键检查点 |
|---|---|---|
| 1 | 将古筝放稳，必要时侧放或使用支架固定 | 避免面板受压、筝体滑动 |
| 2 | 将旧弦完全放松 | 弦不再有明显张力后再拆卸 |
| 3 | 取下该弦的筝码 | 避免旧弦突然崩断时码子跳起 |
| 4 | 从琴尾/S形穿弦孔与岳山处分别抽出旧弦 | 不要硬拽仍带张力的弦 |
| 5 | 检查弦轴、岳山弦槽和穿弦孔 | 无毛刺、无卡弦、弦轴不打滑 |
| 6 | 将新弦固定端从琴尾/背板穿弦孔穿入 | 弦应落在前后岳山的既定弦槽内 |
| 7 | 将弦拉至琴头弦轴处 | 不与邻弦摩擦、不跳槽 |
| 8 | 将弦穿入弦轴小孔，留出约 1.5–4 cm | 长度以能折回并缠绕数圈为宜 |
| 9 | 将弦头折回、紧贴弦轴 | 确保第一圈能压住弦头 |
| 10 | 用手预绕 1–3 圈 | 单层、平行、方向统一、不交叉 |
| 11 | 一手拉住弦，另一手用扳手缓慢收紧 | 弦保持走向稳定，不跳槽 |
| 12 | 弦接近相邻弦张力后，放回筝码 | 码位正确、码脚平稳 |
| 13 | 用调音器调至目标音 | 小幅调整，不要猛拧 |
| 14 | 按压码子两侧并复调 | 直到连续按压后音高基本不变 |
| 15 | 检查弦尾、码子、岳山与邻弦 | 无杂音、无移动、无卡弦 |

## 3. 分音区注意事项

### 3.1 高音区：约第 1–5 弦

| 项目 | 注意事项 |
|---|---|
| 主要风险 | 弦细、张力敏感，码位错误时极易断弦 |
| 码位 | 先确认码子位于前后岳山弦点的合理连线上；若码子太靠左，应先恢复码位，不能靠拧弦轴硬拉到音高 |
| 弦轴缠绕 | 通常约 2–3 圈即可；重点是整齐、压住弦头，不要绕很多圈 |
| 加张力方式 | 每次只拧少量，边拧边拨弦听音；接近目标音后改为小幅调整 |
| 新弦处理 | 轻压、多次，不要猛按；若音持续下降，先检查码位、弦槽和缠绕，再补拧 |
| 断弦处理 | 同一根弦连续崩断时立即停手，检查码位、缠绕、岳山弦槽是否有毛刺或卡弦 |

### 3.2 中音区：约第 6–16 弦

| 项目 | 注意事项 |
|---|---|
| 主要特点 | 张力较稳定，适合作为熟悉换弦手感的区域 |
| 码位 | 以相邻弦为参照，保持弦距均匀；码脚完全落在面板上，不歪斜、不悬空 |
| 弦轴缠绕 | 通常约 1–2 圈；保持单层平行，弦头折回并压紧 |
| 上弦要点 | 先拉直弦再收紧；一手拉住弦，避免在岳山或穿弦孔处卡住、跳槽 |
| 稳定性处理 | 调音后在码子两侧反复按压；音下降则补调，直到稳定 |

### 3.3 低音区：约第 17–21 弦

| 项目 | 注意事项 |
|---|---|
| 主要风险 | 弦粗、回弹力强，弦头未锁住或缠绕错误时容易回松 |
| 弦头锁定 | 穿出弦轴孔后，将短端向内折、紧贴弦轴；必须被第一圈牢牢压住 |
| 弦轴缠绕 | 可绕约 3–5 圈，但必须每圈平铺、不交叉、不叠压 |
| 收紧方向 | 确认扳手向“紧”的方向转动时，弦向弦轴根部/内侧平整缠绕，而不是把已绕的圈推松 |
| 弦轴检查 | 若怎么拧都无效，或一松手就回转，应检查弦轴是否打滑、螺纹是否异常；不要继续硬拧 |
| 码位 | 低音码间距较宽，码脚必须放稳；码位不当会造成移动、杂音或音准不稳 |

## 4. 筝码检查清单

| 检查项 | 合格标准 | 常见错误 |
|---|---|---|
| 码位方向 | 码子大致位于前后岳山两个弦点的连线上 | 码子明显偏左或偏右 |
| 弦距 | 与相邻弦保持均匀距离 | 单根码子被随意挪动，弦距忽宽忽窄 |
| 码脚接触 | 码脚全部平稳接触面板 | 码脚悬空、面板受力不均 |
| 码子姿态 | 码子不歪、不晃、不移动 | 码子倾斜、弹奏时移动 |
| 弦与码槽 | 弦正落在码子顶端嵌弦槽中央 | 弦卡边、偏向一侧 |
| 音高与张力 | 达到目标音时张力与相邻弦协调 | 靠过度拧紧弦轴弥补错误码位 |

## 5. 弦轴缠绕手法

正确顺序可记为：**穿孔 → 折头 → 压头 → 平行绕 → 拉紧 → 慢调**。

| 环节 | 操作要点 | 禁止事项 |
|---|---|---|
| 穿孔 | 将弦穿过弦轴小孔，留出适合缠绕的短端 | 留得过短，导致无法折回锁头 |
| 折头 | 将短端折回，紧贴弦轴 | 弦头松松搭在孔边 |
| 压头 | 第一圈压住折回的弦头，形成自锁 | 第一圈没有压住弦头 |
| 平行绕 | 后续圈保持同一方向、同一层，圈与圈并排 | 交叉、打结、叠成团 |
| 拉紧 | 一手持续拉住长端，一手缓慢转动弦轴 | 不拉弦、让弦跳槽或回弹 |
| 慢调 | 小幅转动弦轴，边调边听 | 一次大幅拧紧，导致弦突然断裂 |

## 6. 换弦后的稳定程序

| 步骤 | 操作 | 目的 |
|---|---|---|
| 1 | 调至目标音，或先略低于目标音 | 避免新弦一次承受过大张力 |
| 2 | 在码子左右两侧各轻压数次 | 帮助新弦和码子进入稳定状态 |
| 3 | 重新调音 | 补偿按压后的音高下降 |
| 4 | 重复“按压—复调” | 直到连续几次按压后音高不再明显下降 |
| 5 | 弹奏数分钟后复查 | 确认实际演奏状态下音准稳定 |
| 6 | 数小时至数天内再复查 | 新弦通常需要时间完全稳定 |

## 7. 换弦后最终复查

- 弦是否居中于码子顶端弦槽。
- 弦是否正确贴住前后岳山弦槽。
- 弦尾是否贴紧弦轴、无翘起、无杂音。
- 弦轴缠绕是否单层、平行、不交叉。
- 码子是否平稳、不移动、不歪斜。
- 相邻弦是否被碰擦或出现杂音。
- 反复按压后音高是否保持稳定。
