# Kahoot 游戏设计学习笔记

这次学习的来源是 Youtube 上几个热门的 Kahoot 教程视频，第一次尝试把视频链接交给 NotebookLM, 看出来的播客内容如何。还是很不错的，我初步听到的内容，已经有了“题型”是Kahoot游戏的关键这个信息。所以，继续听下去吧，让我们一起学学怎么样在一线的英语课堂或者任何课堂上，调动学生的积极性，开始互动式的课堂。

我听到的关键词：

- 视觉策略
- 节奏感

术语：

| 术语 | 定义和解释 |
| --- | --- |
| Kahoot! 课程 (Kahoot! Course) | 一种高阶教学组织形式，允许教师将多个 Kahoot 测验、文档、视频及故事整合在一起，并划分为不同的“模块（Modules）”，用于系统化教学或多科目综合复习。 |
| 经典模式 (Classic Mode) | 实时互动游戏中的个人独立竞答模式，每位玩家使用各自的设备独立阅读题目并作答，根据答题正确率和速度计算得分。 |
| 组队模式 (Team Mode) | 实时互动游戏中的团队竞赛模式，支持“多人共享一台设备”或“一人一机”。在参赛人数较多且受限于免费版人数上限时，共享设备模式是理想的解决方案。 |
| Kahoot! AI | 系统内置的智能生成工具，可根据教师输入的关键词主题、网站链接或上传的 PDF 教材，自动生成相关题目与备选答案，节省手动出题时间。 |
| 游戏 PIN 码 (Game PIN) | 实时游戏大厅或异步作业生成的一串唯一数字代码，玩家无需登录账号，只需在 Kahoot! App 或网站输入此代码即可加入对应的游戏。 |
| 试算表导入 (Import Spreadsheet) | 通过下载官方 Excel 模板，批量填入题目、选项、时限与正确答案后一次性上传至 Kahoot! 的出题功能，适用于制作题量较多的测试。 |
| 玩家设备显示题目 (Show questions on player devices) | 一项关键的控制台设置。开启后，题目和答案选项将同步呈现在玩家的手机/平板屏幕上，而非仅显示在主持人的投影大屏上，特别适合大型场地。 |
| 作业模式 (Assign / Challenge) | 一种异步学习模式，教师规定截止日期并生成链接或 PIN 码，让学生以自定步调独立完成测验，支持随机答案顺序和自动生成昵称等设置。 |
| 报告 (Reports) | Kahoot! 提供的后台数据统计区，汇总记录每次实时游戏或作业的学生答题表现，列出困难题目及需要辅导的学生名单，作为形成性评估的依据。 |
| 星号标识 (Star Icon) | 界面中用于标识 Premium / 付费功能的视觉符号。凡带有星号的题型（如填空题、多选题）、版型或高级 AI 功能，均需升级付费账号方可使用。 |
| 资料库 (Library) | 教师管理个人创作成果的集中区域，包含自己建立的 Kahoot! 测验、课程，以及从公共搜索（Discover）区复制并保存的他人共享资源。 |
| 乱码与编码问题 (Encoding Issues) | 早期或特定版本中可能出现的语言显示异常现象（如繁体中文无法正确显示而呈现乱码），可通过系统更新或界面语言重置恢复正常。 |
